# Active Change Specs Reserve

This directory is reserved for future active OpenSpec delta specifications.

The current repository state is intentionally represented by the stable As-Is baseline under [../specs/README.md](../specs/README.md). This directory should remain empty of active delta specifications while the baseline is being used as the reference implementation description.

## Purpose of this directory

Use this directory only when a concrete future change is being proposed, applied, or archived in the OpenSpec workflow. It is not used for the current implementation baseline.

## Current state

There are no active delta specifications in this directory for the verified baseline. If a future change is introduced, it should be created as a new change artifact in this directory through the OpenSpec workflow rather than by editing the As-Is baseline documents directly.
